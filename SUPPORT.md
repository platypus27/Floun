# Support

## Questions and usage help

Use [GitHub Discussions](https://github.com/platypus27/floun/discussions) for installation questions, usage help, migration-planning discussion, and ideas that are not yet actionable feature requests.

Use the structured [GitHub issue forms](https://github.com/platypus27/floun/issues/new/choose) for reproducible bugs, scoped feature requests, and cryptography-rule proposals.

For Chrome Web Store support, contact [ngaoyu27@gmail.com](mailto:ngaoyu27@gmail.com).

## Security and privacy

Do not post vulnerabilities, API keys, credentials, raw tokens, or private browsing data in Discussions or issues. Follow [SECURITY.md](SECURITY.md) for private vulnerability reporting. Privacy practices are described in [docs/store/PRIVACY_POLICY.md](docs/store/PRIVACY_POLICY.md).

## Scope

Community support is provided on a best-effort basis. Floun reports browser-visible migration signals and is not a substitute for a professional security assessment.
